# 🚀 JavaScriptBasic

> A beginner-friendly course to master the fundamentals of JavaScript.

---

## 📚 What You'll Learn

| Topic | Description |
|-------|-------------|
| 🔢 **Data Types** | Create and use primary data types in JavaScript |
| 🔀 **Conditionals** | Control flow using `if`, `else`, and `switch` statements |
| 🔁 **Loops** | Iterate with `for`, `while`, and `do...while` loops |
| 🧩 **Functions** | Write and call your first JavaScript functions |
| 📦 **Arrays** | Store and manage ordered collections of data |
| 🗂️ **Objects** | Organize data using key-value pairs |

---

## 🛒 Final Project: eCommerce Shopping Cart

By the end of this course, you'll apply everything you've learned to build the **core functionality of an eCommerce shopping cart** — a real-world project that ties all concepts together.

---

## 🛠️ Prerequisites
